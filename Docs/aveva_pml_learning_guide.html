RESEARCH NOTES · 官方文件補充

PML 不只一種用法

閱讀官方指南時，先確認你正在使用 PML 1 還是 PML 2，以及目前 E3D/PDMS 版本。不同工作情境可能使用不同語法與 API。

01 · LANGUAGE

PML 1 與 PML 2 並行

PML 2 常用於 Forms & Menus、物件與方法；規則和報表範本等工作可能仍採用 PML 1 expressions。先從需求和官方章節確認適用語法。

02 · GUI

表單是物件，互動靠 Callback

官方指南將表單描述為全域變數代表的物件；控制項是表單成員，使用點記號存取。Callback 可執行表達式、函式或 method。

03 · REFERENCE

按主題查參考目錄

官方參考目錄另有陣列、DO VALUES/INDICES、DB 元件存取、錯誤處理、檔案 I/O、PML tracing 與 Add-in 章節，適合實作時查閱。

04 · VERSION

以安裝版本文件為準

網路上可找到 E3D 1.1、2.1、3.1 等不同版本文件。語法和功能可能有版本差異；實作前請在公司環境核對對應版本。

學習建議　先用官方 Customisation User Guide 學概念，再用 Software Customisation Reference Manual 查物件成員與方法；遇到版本差異，以專案安裝版本及管理員設定為準。
