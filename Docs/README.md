# AVEVA Marine 與二次開發課程

[← 學習中心首頁](../index.html)

給開發人員的完整課程：先建立入門與資料模型的概念，再依船體、舾裝、目錄與圖面理解船舶設計業務，進入二次開發技術，最後補上系統管理與維運。共 47 章與 5 個附錄，另有兩門獨立課程（PML 互動課程、造船領域知識）。每份閱讀頁底部都有「上一篇／下一篇」導覽。

從 [第 0 章　課程總覽與知識地圖](ch00_knowledge_map_zh-TW.reading.html) 開始，裡面有各章知識點清單、12 週進度與能力等級。

## 練習工具

- [PML 互動課程](aveva_pml_learning_guide.html)：8 個學習階段、6 個逐步實作工作坊、逐行執行動畫、範例庫、官方主題地圖與小測驗，搭配第 11–13 章。
- [造船領域知識](shipbuilding_fundamentals.html)：10 個單元的獨立課程，從船舶生命週期、主要尺寸、幾何性能、船體結構、建造流程，到舾裝、塗裝、焊接檢驗與中英日術語，每個單元都標示與 AVEVA 的對應。
- [Marine 3D 學習實驗室](marine_3d_lab.html)：切換船體、設備與管線，搭配第 3–7 章。

## 維護說明

- 修改任何章節的 `.md` 後，執行 `python -X utf8 build_reading_pages.py`，重新產生 `.reading.html` 閱讀頁。
- 新增章節時，在 `build_reading_pages.py` 的 `books` 清單加入，並同步更新本檔、`ch00` 知識地圖與 `../index.html`。
- 每章結構：學習目標 → 概念 → 畫面與圖解 → 範例 → 開發人員須知 → 練習 → 自我檢核 → 資料來源。
- 標示〔待核對〕的項目，在公司版本確認後請改寫為確定內容並移除標記。
- 全站支援淺色／深色（夜間）模式：偏好存在 `localStorage` 的 `aveva-theme`，未設定時跟隨系統 `prefers-color-scheme`。修改閱讀頁主題樣式請改 `build_reading_pages.py` 的 `html[data-theme=dark]` 規則；四個手寫頁面（`index.html`、`shipbuilding_fundamentals.html`、`aveva_pml_learning_guide.html`、`marine_3d_lab.html`）則在各自 `<style>` 內維護。

## 版權與適用範圍

課程內容依 AVEVA 官方公開文件、開放取用論文與開源範例自主撰寫，不是官方手冊的翻譯，未收錄未經授權轉載的訓練手冊。官方文件多為 E3D 2.1 版本，與 AVEVA Marine 12.x 可能有差異，實際操作請核對公司安裝版本、授權與專案規範。
